# Reference

Tài liệu chi tiết phục vụ một task đã được mở trong `../MVP_SHIP_PLAN.md`.
Các file ở đây không tự tạo priority hoặc authorization.

## Design

- `Design/COMBAT_GRAMMAR.md` — **canonical** cho combat reality, weapon/enemy role và hook test.
- `Design/SKILL_SYSTEM_DESIGN.md` — **canonical** cho skill layers, candidates và icon inventory.
- `Design/CAMPAIGN_AND_PROGRESSION.md` — **canonical** cho selector, unlock và progression boundaries.
- `Design/GAMEPLAY_DESIGN.md` — historical GDD nền; superseded ở các phần combat/roadmap.
- `Design/ECONOMY_DESIGN.md` — economy/gacha/save intent.
- `Design/WEAPON_DESIGN.md` + `../WeaponRosterMapping.json` — historical roster/tuning reference;
  intended family role hiện nằm trong `COMBAT_GRAMMAR.md`.
- `Design/CAMPAIGN_BALANCE_TABLE.md` — snapshot balance sinh từ asset.
- `Design/SCREEN_FLOW.md` + `Design/SCREEN_SPECS.md` — target screen behavior.

## Technical

- `Technical/CORE_WIRING_DIRECTIVE.md` — ràng buộc kiến trúc gốc.
- `Technical/PROFILE_SAVE.md` — save contract.
- `Technical/PREFAB_CONVENTIONS.md` — prefab rules.
- `Technical/EDITOR_SETUP_CHECKLIST.md` — editor workflow.
- `Technical/TASK1_SPAWN_NAVMESH_GENERATOR.md` — spawn/NavMesh contract.
- `../ENEMY_ROSTER_AUDIT.md` — VAT enemy audit generated bởi editor tool.
- `Technical/PlayerRigSocketIncident.md` — incident bắt buộc đọc trước khi đụng Player rig.

## UI

- `UI/UI_ARCHITECTURE.md` — runtime/prefab architecture.
- `UI/UI_REDESIGN_SPEC.md` — owner-authored presentation specification.
- `UI/MANUAL_TEST_FLOW_UI.md` — manual regression checklist.
- `UI/UIRef/` — design source material.

## Audio

- `Audio/AUDIO_SHIP_LIST.md` — authority duy nhất cho cue inventory, source pack, generation brief,
  voice budget, execution order và Definition of Done audio.
