**Total VAT texture footprint:** 62.1 MB uncompressed, counting BOTH maps per enemy: the position map (RGBAHalf, 8 B/texel) and the animated-normal map (RGB24, 3 B/texel).

The normal map is what makes toon shading follow the animation - without it the mesh
keeps its bind-pose normals and the cel terminator stays frozen while the body moves.
If this budget needs cutting later, the cheapest wins are dropping unused clips and
lowering the 30 fps bake rate - both shrink frame count, which scales both maps.

## Blocked by source data

- **HUGO Gorilla** (`enemy.gamwill.hugo`): the source mesh `Hugo` has **16,567 vertices**.
  The VAT position texture is `Texture2D(vertexCount, totalFrames)`, so its width would
  exceed `SystemInfo.maxTextureSize` (**16,384**) and the bake cannot be created. The mesh
  also carries 3 submeshes/3 `Standard` (non-URP) materials, which the single-submesh VAT
  output cannot represent. Baking HUGO requires mesh decimation plus URP material
  conversion; it is intentionally excluded from the roster. Cactus Boss and Skeleton Giant
  serve as the late-campaign bosses instead.
