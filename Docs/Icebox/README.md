| *(không có file)* Character metal riêng | Đã **CẮT khỏi MVP** ở M5+ Toon Unification: ở cỡ nhìn thực tế nó không tăng khả năng đọc hình, còn noise/brushed grain thì hoặc thành vết bẩn hoặc biến mất.
